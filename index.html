Google Sheet Connection

Dashboard directly Google Sheets API se authenticate nahi kar sakta (browser security ki wajah se). Isliye ek free Google Apps Script Web App banao apni Sheet pe — ye ek bridge ki tarah kaam karega. Neeche wala script apni Sheet ke Extensions → Apps Script me paste karo, Deploy → Web App karo, aur jo URL mile wo yaha neeche paste kar do.

⚡ Updated (faster): refresh ab 4 batches ek saath (parallel) load karta hai + Upload ka duplicate-check ab poore sheet ki jagah sirf Ticket ID column padhta hai — dono kaafi tez ho gaye hain, aur ek progress bar bhi dikhega (% + time bacha hua). Agar pehle se koi purana script connected hai, to neeche se latest code copy karke apni Sheet ke Apps Script me paste karo aur dobara Deploy karo (Manage deployments → Edit → New version → Deploy — URL wahi rahega, dobara paste karne ki zaroorat nahi).

🔒 Locked to protect the connected Sheet — click the lock to edit.

🔀 Alag Sheets (optional)

Default: har module upar wali hi Sheet use karta hai. Kisi module ke liye bilkul alag Google Sheet + apna Apps Script Web App use karna hai to us Sheet mein bhi wahi same Code.gs script paste + Deploy karo, mila hua URL neeche add karo. Abhi sirf Dipcheck aur Audits label wale row hi kaam karte hain (naam bilkul yehi type karna) — koi bhi naya custom label add kar sakte ho, wo save ho jayega but tabhi kaam karega jab uske liye aage code mein wire kiya jaye.

⚠️ Yaha jo save karoge wo sirf isi browser mein save hota hai (GitHub-hosted link har user ke apne browser mein alag settings rakhta hai). Agar tumne GitHub Gist pointer (neeche "Locked" wali line mein mention) set kar rakha hai taaki main URL sabke liye ek jaisa reflect ho, to usi Gist ko JSON format mein bhi likh sakte ho taaki ye Dipcheck/Audit rows bhi sabke liye automatically apply ho jayein:
{"webAppUrl":"...","moduleUrls":[{"label":"Dipcheck","url":"..."},{"label":"Audits","url":"..."}]}
Purana plain-URL-only Gist bhi bilkul pehle jaisa chalta rahega — sirf main URL update karega.

🆕 Setup tabs in this connected Sheet

Ye button isi connected Sheet ke andar — jo URL upar paste kiya hai usi mein — jo bhi tab missing hai wo bana dega, par role ke hisab se: Admin click kare tho Audits (saare 108 columns headers + is dashboard ka current data bhi copy ho jata hai), Dipcheck (saved dipchecks ke liye), Config (role settings ke default values ke saath), Users, LoginLog, aur Parameter (QC checklist, sab default parameters ke saath already bhare hue) — sab ban jate hain. Auditor / Manager (ya koi bhi non-admin) click kare tho sirf Audits aur Dipcheck tabs (header row ke saath, bina kisi data row ke) bante hain — Config, Users, LoginLog, Parameter unke liye nahi banaye jaate. Koi naya alag sheet nahi banta — sab kuch isi connected Sheet mein ho jata hai. Jo tab pehle se maujood hai use bilkul touch nahi karega (data safe rahega); sirf jo missing hai wahi banega.
